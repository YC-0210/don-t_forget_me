# 別忘了帶我走 🎒

皮皮是你的隨身小物守護夥伴。在同一個地方停留滿 20 分鐘後，離開時就提醒你確認學生證、水壺、鑰匙，以及自己新增的物品。

## 開啟繁體中文版

App 支援 **繁體中文（zh-Hant）** 與英文，會依 iPhone 的語言偏好顯示。也可以到 iPhone「設定」→「App」→「別忘了帶我走」→「語言」，選擇繁體中文。若沒有語言選項，請先在 iPhone 的「語言與地區」加入繁體中文。

首頁、引導、物品清單、設定、輔助使用標籤、錯誤訊息、通知和定位權限說明均提供繁體中文。自己輸入的物品名稱會保留原文。

## 在 Xcode 執行

1. 開啟 `DontForgetMe.xcodeproj`，選擇 `DontForgetMe` scheme。
2. 選擇 iPhone 模擬器，按 Run。最低支援 iOS 17。
3. 可在 Edit Scheme → Run → Options 將 App Language 設為 Chinese, Traditional，App Region 設為 Taiwan。
4. 要安裝到實體 iPhone，請在 Signing & Capabilities 選擇你的 Apple 開發團隊，再選擇連接的裝置執行。

專案已包含 Xcode project，不必先安裝其他套件。若修改專案設定，可用 `xcodegen generate` 從 `project.yml` 重新產生專案。

## 使用方式

- 開啟通知，將定位權限設為「永遠」，並開啟「精確位置」與「背景 App 重新整理」。
- 到「我的物品」新增或勾選想被提醒的小物，回首頁點選「開始守護」。
- 停留滿 20 分鐘後，離開約 150 公尺的範圍，就會觸發物品確認提醒。
- 提醒每分鐘重複一次。**開啟 App 本身不會停止提醒**，請在清單裡點選「停止提醒」或「都帶齊了，出發！」。
- 可以不勾選物品，直接停止提醒。暫停守護不會停止已經開始的提醒。

## 實際使用限制

皮皮偵測的是手機的位置，無法確認物品真的帶在身上。GPS、背景執行與通知送達時間由 iOS 管理，不能保證在踏出門口的瞬間提醒。強制關閉 App、專注模式、關閉通知、定位權限或系統電池管理，都可能影響提醒。背景定位也可能增加耗電量。

資料只儲存在這部裝置，不需要帳號，也不會上傳位置或記錄移動軌跡。

## 測試

英文與繁體中文各有完整 UI 測試：新增物品、重開 App、模擬停留後離開、實際等待背景重複通知、還原確認進度，以及停止提醒。停留的時間與座標使用測試注入，通知則使用真正的 iOS 模擬器通知服務。

實體 iPhone 的鎖定狀態、GPS 漂移、耗電量和通知延遲仍需實地測試。測試證據見 `verification/TRADITIONAL-CHINESE.md`；實機驗收步驟見 `verification/DEVICE-CHECKLIST.md`。
